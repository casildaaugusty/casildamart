# CASILDAMART

CASILDAMART is an online shopping web application built using Spring Boot, Java, MySQL, HTML, CSS, and Thymeleaf.

## Features

- User Registration
- User Login
- Buyer and Seller Roles
- Product Listing
- Add Products to Cart
- Remove Products from Cart
- User-Specific Cart
- Checkout
- Place Order
- Order Success Page
- Seller/Admin Dashboard
- Add Product
- Manage Products
- Delete Product
- View Orders
- Customer Reviews

## Technology Used

- Java
- Spring Boot
- MySQL
- HTML
- CSS
- Thymeleaf
- Maven

## Project Description

CASILDAMART is an e-commerce web application that allows users to register, log in, browse products, add products to their cart, place orders, and provide reviews.

The application also provides seller/admin features for adding, managing, deleting products and viewing orders.
